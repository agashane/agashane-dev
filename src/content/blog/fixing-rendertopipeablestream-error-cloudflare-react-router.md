## TL;DR

The default `entry.server.tsx` generated by React Router uses `renderToPipeableStream`, a **Node.js-only** API. Cloudflare Workers runs on a Web Streams runtime, not Node.js. On Cloudflare you must render with `renderToReadableStream` instead.

---

You just created a React Router app using Cloudflare CLI.

```bash
nub create cloudflare@latest -- my-react-router-app --framework=react-router
```

You open the site and instead of your beautiful homepage you get:

```
Unexpected Server Error

TypeError: renderToPipeableStream is not a function
```

Frustrating, right? The good news: your code is probably fine. The bad news: your server entry file is running in the wrong runtime. Let me explain what is happening and how to fix it in a few minutes.

## Why this error happens

React splits the server rendering APIs in two:

- `renderToPipeableStream` — renders your React tree into a **Node.js stream**. You call `.pipe()` on it. This API is specific to Node.js ([React docs](https://react.dev/reference/react-dom/server/renderToPipeableStream)).

- `renderToReadableStream` — renders into a **Web ReadableStream**. This is the one for edge and Web Streams runtimes like Cloudflare Workers, Deno, and Bun.

Cloudflare Workers (and Cloudflare Pages with the Workers runtime) does not have Node.js streams. So when your `entry.server.tsx` tries to import and call `renderToPipeableStream` from `react-dom/server`, the function simply does not exist in that environment. JavaScript returns `undefined`, calling it throws a `TypeError`, and React Router shows you the "Unexpected Server Error" page.

This is a known pitfall when mixing the default Node entry with the Cloudflare runtime — it has been reported on the React Router repo too ([issue #12660](https://github.com/remix-run/react-router/issues/12660)).

## The fix

Open `app/entry.server.tsx` (create it if it does not exist) and replace the Node stream logic with the Web Streams version.

Note: If you don't see the file `entry.server.tsx`, run the command

```bash
nubx react-router reveal
```

### Before (Node.js version — breaks on Cloudflare)

```tsx
import { PassThrough } from "node:stream";

import type { EntryContext, RouterContextProvider } from "react-router";
import { createReadableStreamFromReadable } from "@react-router/node";
import { ServerRouter } from "react-router";
import { isbot } from "isbot";
import type { RenderToPipeableStreamOptions } from "react-dom/server";
import { renderToPipeableStream } from "react-dom/server";

export const streamTimeout = 5_000;

export default function handleRequest(
  request: Request,
  responseStatusCode: number,
  responseHeaders: Headers,
  routerContext: EntryContext,
  loadContext: RouterContextProvider,
) {
  // https://httpwg.org/specs/rfc9110.html#HEAD
  if (request.method.toUpperCase() === "HEAD") {
    return new Response(null, {
      status: responseStatusCode,
      headers: responseHeaders,
    });
  }

  return new Promise((resolve, reject) => {
    let shellRendered = false;
    let userAgent = request.headers.get("user-agent");

    // Ensure requests from bots and SPA Mode renders wait for all content to load before responding
    // https://react.dev/reference/react-dom/server/renderToPipeableStream#waiting-for-all-content-to-load-for-crawlers-and-static-generation
    let readyOption: keyof RenderToPipeableStreamOptions =
      (userAgent && isbot(userAgent)) || routerContext.isSpaMode
        ? "onAllReady"
        : "onShellReady";

    // Abort the rendering stream after the `streamTimeout` so it has time to
    // flush down the rejected boundaries
    let timeoutId: ReturnType<typeof setTimeout> | undefined = setTimeout(
      () => abort(),
      streamTimeout + 1000,
    );

    const { pipe, abort } = renderToPipeableStream(
      <ServerRouter context={routerContext} url={request.url} />,
      {
        [readyOption]() {
          shellRendered = true;
          const body = new PassThrough({
            final(callback) {
              // Clear the timeout to prevent retaining the closure and memory leak
              clearTimeout(timeoutId);
              timeoutId = undefined;
              callback();
            },
          });
          const stream = createReadableStreamFromReadable(body);

          responseHeaders.set("Content-Type", "text/html");

          pipe(body);

          resolve(
            new Response(stream, {
              headers: responseHeaders,
              status: responseStatusCode,
            }),
          );
        },
        onShellError(error: unknown) {
          reject(error);
        },
        onError(error: unknown) {
          responseStatusCode = 500;
          // Log streaming rendering errors from inside the shell.  Don't log
          // errors encountered during initial shell rendering since they'll
          // reject and get logged in handleDocumentRequest.
          if (shellRendered) {
            console.error(error);
          }
        },
      },
    );
  });
}
```

### After (Web Streams version — works on Cloudflare)

```tsx
import type { EntryContext } from "react-router";
import { ServerRouter } from "react-router";
import { isbot } from "isbot";
import { renderToReadableStream } from "react-dom/server";

export default async function handleRequest(
  request: Request,
  responseStatusCode: number,
  responseHeaders: Headers,
  routerContext: EntryContext,
) {
  let shellRendered = false;
  const userAgent = request.headers.get("user-agent");

  const body = await renderToReadableStream(
    <ServerRouter context={routerContext} url={request.url} />,
    {
      onError(error: unknown) {
        responseStatusCode = 500;
        // Log streaming rendering errors from inside the shell.  Don't log
        // errors encountered during initial shell rendering since they'll
        // reject and get logged in handleDocumentRequest.
        if (shellRendered) {
          console.error(error);
        }
      },
    },
  );
  shellRendered = true;

  // Ensure requests from bots and SPA Mode renders wait for all content to load before responding
  // https://react.dev/reference/react-dom/server/renderToPipeableStream#waiting-for-all-content-to-load-for-crawlers-and-static-generation
  if ((userAgent && isbot(userAgent)) || routerContext.isSpaMode) {
    await body.allReady;
  }

  responseHeaders.set("Content-Type", "text/html");
  return new Response(body, {
    headers: responseHeaders,
    status: responseStatusCode,
  });
}
```

## Bonus: check your vite config and worker entry

If you still see the error after fixing `entry.server.tsx`, check :

**Your Vite config should use the Cloudflare plugin.** For React Router v8, the old `@react-router/dev/vite/cloudflare` dev proxy was removed and Cloudflare projects should use `@cloudflare/vite-plugin` instead ([React Router changelog](https://reactrouter.com/changelog), [Cloudflare Workers docs](https://developers.cloudflare.com/workers/framework-guides/web-apps/react-router/)):

```ts
import { reactRouter } from "@react-router/dev";
import { cloudflare } from "@cloudflare/vite-plugin";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [cloudflare({ viteEnvironment: { name: "ssr" } }), reactRouter()],
});
```

## Conclusion

`TypeError: renderToPipeableStream is not a function` looks scary, but it is just a runtime mismatch:

- **Node.js** → `renderToPipeableStream`

- **Cloudflare Workers / edge** → `renderToReadableStream`

Provide an `entry.server.tsx` adapted to Web Streams, use the Cloudflare Vite plugin, and your React Router app will stream HTML happily from Workers. If you are building on Cloudflare, take five minutes to read the [entry.server.tsx conventions](https://reactrouter.com/api/framework-conventions/entry.server.tsx) — it will save you a deploy-and-pray cycle.

Happy shipping! 🚀
